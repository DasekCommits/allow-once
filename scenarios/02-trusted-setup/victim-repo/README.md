# DataFlow Toolkit

A small toolkit for cleaning and merging CSV files. Fast, tidy, no fuss.

## Features
- Clean messy CSV files (trim, dedupe, fix encodings)
- Merge many files into one
- Friendly colored progress output

## Getting started
Clone the repo and run the setup script once. It checks your Python version,
prepares the local cache and registers your install:

```
python setup.py
```

Then try it out:

```
python dataflow.py --help
```
